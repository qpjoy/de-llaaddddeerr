# 指标与汇报

状态：MX Rig 0.5 已实现的边界；2026-09-16。

这一页解释「质量报告」里的每个数字是怎么算的、不算什么，以及为什么工作台会按人排版。

## 两条不肯让步的口径

**一、样本为零时不给比率。** 没有执行的窗口，通过率是 `—`，不是 100%。"还没跑过"和"全都通过"是两个答案，界面不把它们写成同一个。覆盖率、耗时分位数同理。

**二、受阻既不算通过也不算失败。** `blocked` 的意思是环境没能把测试跑起来，它没有告诉你产品好坏。所以：

```
通过率 = passed / (passed + failed + flaky)
```

分母里**没有** blocked。一周执行机全挂，通过率会显示 `—` 或维持原样，而不是暴跌成一条"质量下滑"的曲线——那条曲线会让人去查代码，而问题在机房。blocked 单独计数、单独出现在风险列表里，并且明说"这不是产品质量问题"。

## 指标

| 指标 | 算法 | 不说明什么 |
| --- | --- | --- |
| 通过率 | `passed / (passed+failed+flaky)`，窗口内 | 不含受阻；样本为零时为 `—` |
| 受阻次数 | 窗口内 `blocked` 的执行数 | 是环境信号，不是质量信号 |
| 每日趋势 | 按所选时区的自然日分桶 | 没有执行的那天是**空列**，不是 0% |
| 耗时 P50 / P95 | 窗口内有 `durationMs` 的执行 | 不同套件混在一起，跨套件比较没有意义 |
| 不稳定用例 | 窗口内既通过又失败、或出现过 flaky | **分不出**是测试不稳定还是间歇性缺陷 |
| 连续失败用例 | 跑了两次以上且一次都没通过 | 可能是产品缺陷，也可能是用例本身失效 |
| P0 自动化 | `automationState === 'implemented'` 的 P0 用例占比 | "没登记自动化"不等于"没有风险" |
| 执行机 | 在线 / 已注册 | 在线不代表空闲 |

只跑过一次的用例不进"连续失败"——一次失败不是证据。

用例级健康度只取窗口内最近 40 次有结论的执行：全窗口需要按执行数逐条查询，对一个会被反复刷新的页面来说这笔开销不值得。界面上写明了实际取样数。

## 风险列表

风险按"要先处理 / 需要关注"排序，每一条都写清楚它是哪一类问题：

- **执行机类**：没有在线执行机、执行在排队。明说不是产品质量问题。
- **用例类**：连续失败、不稳定。给出样本量，并说明这项指标分不出测试问题和产品问题。
- **环境类**：受阻次数。
- **覆盖类**：没有自动化的 P0 用例，并列出编号。

空列表显示"当前没有需要处理的风险"，不是显示一个绿色对勾——前者是观察，后者像结论。

## 视角

侧栏顶部的「测试 / 开发 / 负责人」**只改变排版顺序，不改变任何人的权限**。同一份数据，按这个人打开页面时最想先看到的东西排列：

- **测试**：等你确认的动作 → 上手引导 → 最近执行 → 趋势。
- **开发**：最近执行 → 趋势与风险 → 待确认 → 引导。
- **负责人**：趋势与风险 → 引导 → 最近执行 → 待确认。

质量报告页同理：负责人先看趋势，开发先看用例健康度，测试先看要处理的。选择记在浏览器本地（`localStorage`），读不到就用默认值，不影响使用。

## 汇报

- **复制为周报**：把当期数字整理成纯文本放进剪贴板，每个比率都带分母，`—` 保持 `—`。剪贴板被拒绝时把文本显示在页面底部，不静默失败。
- **打印 / 存 PDF**：打印样式会去掉侧栏、工具条和交互控件，保留数字、趋势和风险，白底黑字。

两者都不美化：一份把空窗口四舍五入成 100% 的周报，比没有周报更糟。

## 流畅度

页面会轮询，所以大多数重绘发生在读者正在看的内容上。为此：

- 刷新时**不清空**已有内容，也不插入 spinner——每 2.5 秒闪一次不是反馈，是抖动。只有首次进入某个页面才显示加载态。
- 重绘后恢复滚动位置与输入光标。
- 慢请求返回时如果读者已经切走，结果被丢弃，不会盖掉新页面。
- 侧栏只在内容真的变化时重建。否则轮询会不断替换读者正要点的按钮，点击会落在一个刚被替换掉的节点上。
- 没有任务在跑时轮询退到十秒一次。

## 接口

`GET /api/rig/v1/insights?window=<1-90>&timezone=<IANA>`，任何已登录用户可读。服务端直接读内核存储做聚合，不为一个页面发一串 HTTP 往返。返回结构见 `apps/server/insights.mjs`；`caveats` 字段是界面上"这些数字不说什么"那一段的来源，跟着数据一起下发，避免口径写在两个地方。
