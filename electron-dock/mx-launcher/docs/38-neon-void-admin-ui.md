# Launcher 管理界面与 Neon Void 的持续同步

日期：2026-10-03。范围：Launcher 管理前端、共用组件、设计示例与静态资源打包；未部署生产。

## 设计来源与边界

以 `demos/ui-design-neon-void` 的组件页及 `ui-design/src` 为设计基准：深色四层背景、青色选中/焦点、4/6/8px 圆角、紧凑控件和分级文字。保留现有业务导航、操作名称、字段及命令含义。Launcher 的业务页面使用 `desktop/neon-void.css` 做布局和密度适配；颜色等基础变量直接引用 `--qp-*`。

本批覆盖工作台、导航、服务与部署、用户/权限目录、发布目录、应用目录、原运维表单及抽屉的共用视觉层。用户/权限/发布/DNS 目录采用完整内容宽度，不再同时展示无关的主机信息检查侧栏；运维页面保留原检查面板。保留表格列与水平滚动，筛选栏按宽度换行。

这是前端更新，不修改账号、登录协议、身份/租户关系、权限判断、网络/VPN、Luopan 产品或部署执行逻辑。新选择器仍把原字段值交给既有处理函数；打开菜单、搜索、筛选本身不增加后台写操作。

## 共用选择器

`ui-design/src/select.js` 提供 `installNeonSelects()`；样式由共用 `styles.css`、`tokens.css`、`select.css` 提供。Demo 与 Launcher 直接消费同一份实现，删除各自旧的用户下拉/示例交互实现。

- 所有当前单选字段统一为自定义下拉；支持文字/值搜索、分组、无结果、空列表、当前选中、禁用选项和禁用分组。
- 支持方向键、Home/End、Enter、Escape、Tab 和输入法组合输入。关闭菜单恢复焦点；表单重绘后按原字段恢复焦点。
- 菜单使用 body 浮层，避免被表格/滚动容器裁切；按可视视口收窄、向上展开并随滚动定位。
- 浮层继承字段所在容器的主题变量，Demo 的浅色/深色切换保持一致。搜索框只保留外层焦点边框。
- 原生 select 保留作为表单值载体，保留 name/FormData、required 校验、reset、input/change 语义；动态字段在绘制前增强。
- 现有代码直接设置 `value`、`selectedIndex`、选项或禁用状态时同步显示。多选/原生列表框和显式 `data-neon-native` 保留原生行为；当前管理界面无此类例外。
- 直接改变单个 option 的 selected 属性且不触发事件的外部集成应调用 `refresh()`；初始化和卸载说明见 `ui-design/README.md`。

## 开发、打包与后续更新

1. 共用交互与视觉在 `ui-design/src` 修改，并同步在 Neon Void Demo 中演示。不要编辑生成的 `desktop/ui-design/`。
2. `pnpm --dir desktop run dev/build` 自动同步设计资产；`check` 校验副本与源文件完全一致。首次直接通过静态服务预览 desktop 时先执行 `pnpm --dir desktop run sync:design`。
3. Electron 打包包含共用资源目录与 `neon-void.css`。生产 `shadow_image_admin_assets` 从共用源目录直接复制相同资源，不依赖开发机生成物。
4. 设计库 build 导出 `select.js/select.css` 子路径及类型声明。本轮没有发布 npm 包；消费已发布版本的 Hub/Rig 不会被自动升级。
5. 原完整 Launcher deploy 可按现有流程发布新静态资源；不要只替换旧的 renderer/styles 两个文件。

## 本地验收

- Desktop build：类型检查、原功能契约、命令目录、新增生产资源装配与抽屉聚焦回归测试。
- 设计库与 Demo build/check；共用选择器浏览器测试覆盖原表单事件/值、动态变更、禁用/分组、输入法、键盘、空状态、校验、重置、浮层、清理与小屏。
- 本机浏览器：工作台 → 服务操作搜索 → 命令预览；用户角色筛选 → 编辑抽屉角色变更 → 草稿保留/Escape；主要导航入口与 1440×1000 / 390×844 布局。
- 原服务部署页面回归继续核验参数、草稿、计划确认、失效、断线查询与服务器隔离；所有操作使用隔离替身。

验收中修复了用户编辑抽屉的延迟自动聚焦：用户已经选中其他字段时不再跳回 Account；关闭/重新打开后的旧回调也不会抢焦点。通过真实页面逐帧操作复现并验证，角色变更后输入草稿保留。

### 视觉对照

| 对照项 | 设计基准 | Launcher 结果 / 有意保留 |
| --- | --- | --- |
| 色彩、边框、圆角 | `ui-design/src/tokens.css` | 直接映射共用变量，不复制另一份色板 |
| 导航与间距 | Demo 的安静侧栏、青色选中 | 应用/业务/运维分组与原路由保留，减少每行重复边框 |
| 字号、密度 | 分级标题和紧凑表单 | 正文 14px、输入 13px / 36px；触控选择器至少 42px |

| 布局 | Demo 的宽内容区、成组控件 | 目录占满内容宽度；服务表单与命令在桌面并排，小屏叠排 |
