## 修改

- 取消本地每月计数硬门槛、每月扣费日和 6/72 小时恢复推测。兼容保留旧配置和审计数据。
- 当前串行 lease 的可信 Requests 响应头校准额度，接受供应商套餐上限变化；迟到的旧 lease 响应无权覆盖新状态。
- 保留跨副本 lease、FIFO、派发预留和未决占用。最近供应商观测与本地可用数分开展示。
- 响应头未知时停止自动派发；可信 reset 到期只放行下一条真实业务请求检查一次，失败后不根据旧 reset 循环。
- 增加 Admin Token 专属的一次性检查许可，5 分钟有效、使用即消耗、有原因与版本检查及审计；只授权下一条业务请求，不立即调用供应商，不改变任何全局开关。

只修改 Facebook 搜索额度策略、管理投影与诊断。Twitter、其他供应商、公共接口合同、历史响应和账单保持原状。MX-H2I 登录与联网不涉及。

## 发布

本次仅本地修改，未执行生产迁移、部署或新付费验证。迁移 169 必须先于新版 Admin/Public 应用。通过原 Hub 部署流程发布 Admin 与全部 Public 副本；混合版本期间旧副本仍可能应用本地硬门槛。无需发布 Launcher。

```bash
MX_INSIGHT_SYNC_LAUNCHER=0 MX_SMOKE_DATA=0 bash scripts/manage.sh ops internal-production deploy
kubectl -n mx-insight-hub rollout status deployment/mx-insight-hub-public --timeout=240s
```

新版本不会将历史 `remaining` 当成供应商原始值，也不会自动恢复旧的 0。若原始观测缺失且供应商 reset 未到，可由管理员填写原因，点击“允许下一条请求检查一次（可能计费）”，等待真实业务使用许可。新回执确认额度后自动校准。不要手动把 used 清零或把本机测试的 16 次写入生产。

只读核验使用 `server/ops/diagnose-facebook-quota.mjs`，v2 同时输出原始供应商观测、本地扣减后次数及最近调用的计费头；兼容旧库，但旧库标记供应商观测字段尚不支持。
