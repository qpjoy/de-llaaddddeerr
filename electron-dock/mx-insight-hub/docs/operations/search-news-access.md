# 数据搜索与新闻发现入口授权

普通租户的菜单和直接页面地址使用同一产品权限检查，均要求控制台
`apikey.read` 及当前调用者业务授权。平台管理员沿用原有产品可见性。

- 数据搜索：至少一个聚合搜索支持的已存平台，或一个
  `data_center_saved_records_<source_type>` 存量类别。
- 新闻发现：至少一个存量类别，例如 `data_center_saved_records_news`。
- 仅有 `ip_risk` / `ip.risk.query`、`source_catalog` 或其他无关授权，
  不显示这两个入口。直接输入页面地址回到现有的首个允许页面。

不新增同名产品能力开关。调用者授权决定产品入口；接口调用仍校验调用者
与实际 Key 的权限交集，旧 Key 不自动扩权。授权后保留原搜索/新闻工作台，
不会替换为通用租户产品页。实时搜索继续要求对应操作权限、运行状态及计费条件。

发布前端构建即可生效，无需迁移数据库或调整现有用户授权。
不修改 Launcher/MX-H2I 登录、联网或数据接口的权限合同。
