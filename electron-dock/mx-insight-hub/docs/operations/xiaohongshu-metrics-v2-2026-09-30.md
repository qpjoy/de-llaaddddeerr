# 小红书详情指标补数（2026-09-30）

## 问题与证据

用户截图中，同一笔记 `6aaa708b0000000025036d6e` 的 PGY 详情返回整组零；博主 `624560f5000000000100ffab` 的 v2 案例列表返回阅读 619、曝光 6499、收藏 27、总互动 107，`total=50`。这些是截图时的观察值，不是当前线上查询结果。

[TikHub 官方 v2 合同](https://docs.tikhub.io/506372191e0) 确认：POST `get_blogger_notes_v2`，请求 JSON 数字参数 `page_number=1`、`page_size=8`、`note_type=0`、`order_type=1`；列表在 `data.data.noteList[].noteInfo`，作者在同行 `userInfo`。翻页仅改变页码，空列表终止。HTTP 200（包括空结果）计采购成本；HTTP 400 不计采购成本。v1 的结构和参数枚举不能混用。

## 实现边界

- 保留 `POST /api/v1/data/xiaohongshu/notes/detail` 和 PGY 别名、`social.posts.analytics` 权限及客户价格。正文、标签和媒体仍来自原详情；同时修正 `userInfo.userId/nickName/avatar` 作者映射。
- 当阅读/曝光任一缺失，或二者均为零时，根据详情提供的作者 ID 查 v2；逐页精确匹配笔记 ID，作者若明确返回也必须一致。原详情没有合法作者 ID 时不猜作者。
- 按用户要求移除固定 15 页上限。找到目标即停止；已查看的唯一笔记数达到 `total`、空页、整页重复或 90 秒预算也停止。非空短页仍继续。90 秒预算包括补数队列等待，只有剩余时间足够覆盖一次上游超时时才派发。补数页不自动重试。
- 直接映射 readNum→views、impNum→impressions、favNum→collected、engageNum→engaged。已有有效详情互动计数保留。只有整组零/缺失详情与同笔记非零列表矛盾时，才清除占位值；列表不提供的点赞、评论、分享返回 null，不能从总互动反推。
- `meta.metricsSupplement` 保留状态、成功解析页数、最近一页 total、命中页和补数采集时间；`meta.metricSources` 标明逐项来源。正文成功而补数受限仍交付正文及状态，不承诺所有笔记均能取到阅读量。

## 成本、权限、缓存与证据

每页独立通过当前 Key/业务权限、操作开关、凭据、队列、速率、预算和成本准入，并记录 `provider_calls.call_role=enrichment` 与完整受限响应。主详情和所有补数页共用一个客户请求、用量和扣费身份。已知拒绝、已收费但解析失败、未知结果分别记录；补数失败停止翻页，正文继续交付。持久化无法确认时不会伪装成功或重发上游。

详情队列和 v2 队列按接口/凭据隔离，均沿用平滑间隔；新的详情共享缓存指纹包含补数合同版本，因此不会继续命中旧版全零快照。本次合同版本升级至 `mx-insight-hub.xiaohongshu-note-metrics.v2`，新请求也不会复用旧版在第 15 页停止的快照；`page_limit` 仅保留用于历史交付重放。原 Idempotency-Key 的交付仍不可变，历史数据不重写。已补数据进入原 canonical/outbox 流程，rawItem 保留补数状态、逐项来源和命中页的 providerCallId/sourcePointer，可关联全部原始证据。

## 启用

管理端“外部数据平台 → TikHub → social.posts.analytics”的原价格编辑表单新增可选采购单价：`xiaohongshu.pgy.blogger-notes.v2`。需要根据实际账户/接口采购证据填写并发布；每页单独计采购成本，不能套用详情单价。币种沿用该操作的价格簿。

该字段留空时原详情服务、旧价格簿和权限继续工作，补数状态为 `not_configured`。代码更新不自动发布价格、启用操作、扩展 Key 权限或修改余额。无需数据库结构迁移；价格仍写入现有不可变 price book 表。配置完成后，使用新的 Idempotency-Key 和 `deliveryMode=refresh` 验证；旧幂等键必然重放旧交付。

补数最长 90 秒叠加原详情排队及安全重试，响应等待可能超过既有 120 秒代理超时。部署时核对 Hub 业务 API 的超时策略；本补丁不改任何 MX-H2I/Launcher 网络或身份配置。客户端断连后已派发调用仍结算留证，不开始新的补数页。
