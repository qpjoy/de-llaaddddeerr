# 抖音和小红书分享链接解析

从平台复制整段分享文案，提取可以用于详情查询的字符串 ID。短链需要联网，路径里已有 ID 的完整作品链接可以离线解析。解析成功表示识别出了链接指向的作品，作品是否仍可访问由详情查询确认。

## 在 Hub 里使用

打开「数据服务 → 分享链接解析」，粘贴一条或多条文案，点击「解析」。可以混合两个平台。选择结果中的详情入口会打开对应产品并填入参数，随后由用户提交查询。

| 平台 | 前往的数据产品 | 接口与参数 |
|---|---|---|
| 小红书 | 小红书笔记画卷 | 正文入口接受由笔记 ID 构成的 `https://www.xiaohongshu.com/explore/<note_id>`。已有 `GET /api/v1/xiaohongshu/app/get_note_info` 也接受 `note_id`。 |
| 抖音 | 社媒与内容数据 → 获取单个作品数据 | `POST /api/v1/data/native/t.api_ab9535a5f6389ce6`，提交 `{"params":{"aweme_id":"<作品ID>"}}`。 |

Hub 的解析 API 是 `POST /api/v1/data/share-links/resolve`。调用者及显式授权的 Live Key 需要 `social` 和 `social.share_links.resolve`。解析计一次请求配额，费用按租户已有套餐或默认策略结算。正文查询各自检查原有权限，执行时沿用原数据产品的计费规则。

解析接口返回 HTTP 429 时，可用 `error.code` 定位限制来源。

| 返回值 | 含义 |
|---|---|
| `plan_burst_exceeded` | Hub 在预留额度时发现该调用方最近一秒已用满套餐。该调用方的所有 Key 和受套餐计量的产品共用名额。本次解析尚未开始，`error.details.retryAfterMs` 提供下次尝试的等待提示。 |
| `resource_admission_limited` | Hub 的 API 进程或 Key 已达到资源上限。`error.details.reason` 会标明 `rate`（速率）、`concurrency`（并发）等具体原因。 |

当一个套餐名额即将释放时，每个 API 进程允许同一调用方最多 16 个解析请求按顺序等候，含队首。为平滑抖动增加的等待预算为 160 毫秒，数据库操作和最终解析还需要各自的时间。请求始终需要通过实际套餐预留，取得名额后只执行一次解析。持续超额仍会返回 429。短链访问平台的耗时还会占用 Key 的并发名额。

~~~sh
curl -sS "$HUB_URL/api/v1/data/share-links/resolve" \
  -H "Authorization: Bearer $HUB_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"text":"小红书 https://xhslink.cn/o/3EUFAcQijZe 抖音 https://v.douyin.com/7h9Ip7hjLRY/"}'
~~~

可选字段 `platform` 接受 `auto`（默认）、`douyin` 和 `xiaohongshu`。每批最多 10 个不同平台链接，`data.results` 按提取顺序返回。同一链接只处理一次，不同短链可能指向同一个 ID。请按每条结果的 `ok` 判断成功或失败。成功项包含 `platform`、`type`、字符串 `postId`，以及平台对应的 `aweme_id` 或 `note_id`。小红书链接携带的 `xsec_token` 可能随结果返回，进入详情页面只传作品 ID。

| 输入短链 | 实测平台类型 | ID |
|---|---|---|
| `xhslink.cn/o/3EUFAcQijZe` | 小红书笔记 | `6afedd3200000000260272af` |
| `v.douyin.com/7h9Ip7hjLRY/` | 抖音图文 | `7711088087472025201` |

对于只有口令的抖音文案，Hub 的社媒与内容数据另有 `POST /api/v1/data/native/t.api_47a9cfa7c14880c8`，参数为 `{"params":{"share_code":"<完整口令>"}}`。需要该详情接口自身的授权，用户明确提交后才调用。[TikHub 抖音口令接口文档](https://docs.tikhub.io/406098637e0)

## 单独调用 Python 脚本

在本目录运行。两个脚本各自只用 Python 标准库，可以单独拷走，也可以在 Python 中导入。

~~~sh
python3 douyin_link.py '复制打开抖音 https://v.douyin.com/7h9Ip7hjLRY/' --json
python3 xhs_link.py '进入小红书 https://xhslink.cn/o/3EUFAcQijZe' --json
~~~

~~~python
from douyin_link import resolve_all as douyin_links
from xhs_link import resolve_all as xhs_links

text = '从聊天里复制的分享文案'
for resolver, field in [(douyin_links, 'aweme_id'), (xhs_links, 'note_id')]:
    for row in resolver(text):
        if row['ok']:
            print(row[field])
~~~

`resolve(text)` 返回首条结果，`resolve_all(text)` 返回本平台结果列表。命令行支持 `--chain` 查看跳转，`--timeout` 调整单次请求超时。以上 Python 工具是独立命令行版本。Hub 在服务端逐跳验证平台域名并限制请求数量、时间及响应大小。两种方式都会标记来自页面扫描的候选结果，见 `uncertain`。只有文字口令时，抖音脚本可以输出 TikHub 口令查询地址，实际调用该接口是另一步。
