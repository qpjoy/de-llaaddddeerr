# DataPort 设计组件

样式基线为用户提供的外部数港设计原型。组件保留原有结构，`styles/dataport.css` 的设计尺寸已从 px 转为 rem，以统一各页面比例；当前品牌、资源文件名与浏览器偏好存储键已统一为 DataPort。`source-manifest.json` 保留初次抽取的来源文件和 SHA256，用于追溯原始设计，不代表适配后文件的校验值。

React 组件依赖由 DataPort 根 package-lock 固定；`@/` 映射到本目录。此包不包含 Next.js 服务端、自有账号、演示订单或支付模拟器。业务适配与 DataPort 少量补充样式放在 `apps/web/`。

运行 `npm run dev:gallery`，访问 `http://127.0.0.1:4279/demos/ui-design-dataport/`。预览提供首页、控制台壳、登录与邀请注册；fixture 明确标注为设计预览，不提交账号或调用真实服务。

控制台沿用原设计的 `SidebarMenuButton` 和 `data-active` 选中态；不要用裸按钮替换，否则会丢失图标与文字的横排布局。支付订单、账户安全和退出登录集中在底部账户上拉菜单，使用现有 DataPort 路由。业务卡片、表格和空状态使用 `harbor-console` 下的样式适配原设计。

新增数据商城复用 Hub 的商品和业务流程，采用 DataPort 蓝色与现有 rem 尺寸；我的接入入口改为“我的订阅”。原型最新版本隐藏商城、未提供账户安全三列卡片；新增账户页使用账号摘要与资料/密码/会话折叠分组，不声称它是原型已有页面。历史画像和商品内容必须来自接口，gallery/隔离样例不得作为真实业务结果。

全站以用户确认的本地截图为视觉基准，公开首页、定价、控制台、登录/邀请注册及 Portal 菜单使用同一套尺寸规则。设计长度按 16px 基准转为 rem；`apps/web/design-scale.css` 在宽度至少 768px 时设置根字号为 80%，手机保持默认字号。响应式断点和不超过 1px 的细线保留 px，不使用整页 `zoom` 或 `transform: scale()`，也不再叠加控制台专属缩放。

默认浏览器字号下，桌面登录弹窗宽 608px（左栏 224px），公开导航高 64px，侧栏约 179px，查询标题 38.4px，搜索框最大宽度 672px。带账号服务错误提示时，登录弹窗高度约 542px；高度随表单状态自然变化。gallery 同样复用生产入口的尺寸规则，查询按钮展示尚未开放状态，不调用真实接口。

登录弹窗保留数港双栏设计，右侧表单独立滚动，关闭按钮始终可达；手机为单栏。样式验收覆盖桌面 1436×703、矮屏 1280×600、手机 390×844，检查登录与邀请注册、侧栏菜单、账户设置、表格及空状态。验收清单见 [界面比例验证](../docs/visual-verification.md)。
