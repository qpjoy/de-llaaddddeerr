# DataPort 设计组件

2026-10-15 对齐用户目录中的 `dataport` 最新原型。`styles/dataport.css` 与 `components/ui/sidebar.tsx` 重新同步原始文件，`source-manifest.json` 记录来源 SHA256；其他条目保留首次抽取的追溯记录。原型目录只读，业务实现位于实际数港的 `apps/web/`。

默认根字号为 100%（16px）。桌面侧栏 224px、公共导航高 80px、查询搜索框最大宽 840px、登录弹窗宽 760px。沿用原型断点和移动端单栏布局，不使用整页缩放。`prototype-parity.css` 最后加载，适配保留真实业务的页面结构；新增样式应先检查原型类，避免继续叠加冲突规则。

导航为新建查询、用量概览、API Keys、我的订阅、账单与发票、接口文档；客服在侧栏底部，企业账号、日志审阅和消息通知从账户菜单进入。菜单和直接地址均保留企业权限校验。消息以弹窗显示，深链接仍可打开完整消息页。

公开定价和控制台共用 `PlanCards`，价格、期限、次数、试用状态均来自后台，不能复制原型假商品。登录沿用统一 MX；企业超管在 SSO 成功后完成专属邀请码校验。文档按企业筛选，仅展示现有 OpenAPI 与调用代码示例，不增加真实调试请求。地图使用后台已有坐标，建议区明确 AI 尚未接入。

原型不再显示 Cookie 通知条或保存侧栏偏好；应用启动只清理旧的界面偏好，认证 Cookie 仍由服务端管理。

`npm run dev:gallery` 保留设计组件预览；不提交账号、不发起真实查询。逐页检查范围、必要业务差异和本次验证见 [2026-10-15 原型对齐验收](../docs/prototype-parity-20261015.md)。
