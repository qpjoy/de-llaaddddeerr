# 订单支付超时展示（2026-10-21）

账单列表、订单详情、筛选与账单导出统一将已超过收银台可用时间的订单显示为“支付超时”。收起“继续付款”和已缓存的收银台链接，保留原订单的“查询付款状态”。超时瞬间点击付款而收到 `payment_checkout_expired` 时，页面立即更新该订单并显示“支付超时，请查询原订单的付款状态。”，不再展示支付中心的英文错误。DataPort BFF 同时按错误码兜底中文提示，兼容发布期间旧 Hub 返回的英文。

## 状态依据与账本边界

- 沿用现有 Alipay 收银台规则：Pay 的 `createdAt` 加 30 分钟、向下取整至秒，剩余时间小于一分钟即不可继续结账；恰好一分钟仍允许。Hub 使用同一规则做只读展示，不采用业务订单创建时间推测付款截止时间。
- `payment_timeout` 是数港展示状态。原始 Pay 状态仍可为 `pending`，不写成取消、失败或已关闭，不延期、不重新创建支付单、不修改既有订单和订阅。
- 已支付和已交付优先于超时；原单仍可查询付款状态，晚到的有效已支付回执照常处理。
- 未创建支付单、未知或无效时间、非 Alipay 渠道不推测超时。列表计数、分页、导出和待付款商品汇总共用同一 SQL 条件，并保留租户与权限校验。历史异常时间不会导致全部账单查询失败。

发布顺序：Hub → DataPort。无需发布 Pay、Launcher 或 Auth，无新数据库迁移、凭据或环境变量调整。Hub 订单展示增加 `paymentExpiresAt` 和 `checkoutAvailable`，原始 `paymentStatus` 保留。
