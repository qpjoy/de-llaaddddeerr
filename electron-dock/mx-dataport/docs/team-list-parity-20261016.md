# 企业账号列表对齐（2026-10-16）

以工作区 `dataport/app/team-space.tsx` 和原型现有 CSS 为只读参考，仅修改数港前端。

## 本次调整

1. 企业概览采用原型的图标、企业名称与底部状态/员工数/角色布局，刷新按钮恢复文字。员工数量按非 owner 成员统计，加载中不显示虚假的 0。
2. 成员列表采用原型的原生表格和成员身份样式：34px 头像、名称/账号双行、独立“你”标记、状态圆点、超管操作栏短横线及底部说明。删除旧的 900px 表格最小宽度、400px 操作列和冲突的概览样式。
3. 行内操作与原型一致，显示“详情”和有权限时的“停用/启用”。资料编辑、分配角色和超管初始密码入口移到详情内；资料与角色分别保存，沿用服务端每次只允许更新一个字段的协议。初始密码仅在用户主动点击后请求，不随打开详情自动读取。
4. 停用/启用先弹出确认窗口，取消不会提交。手机端表格自身横向滚动，列标题和账号类型不逐字换行；键盘可以到达右侧操作。
