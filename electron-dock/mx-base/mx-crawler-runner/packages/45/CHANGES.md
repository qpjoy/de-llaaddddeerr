# 上游适配说明

保留 AudioSpider 固定提交 cbc055436b71fa3f3882bedc95b65bad4dec2553 的完整原始源码、依赖声明与 MIT 许可证；见 upstream/provenance.json。运行代码位于 src/audiosource_45，不直接导入上游配置，避免在包目录创建数据或日志。

本项目保留小宇宙的公开网页/接口取数方式；分离发现、采集、下载和本地列表，增加参数校验、超时、限量、独立 SQLite、连接池、JSON 结果与错误记录。不依赖其他平台目录。

小宇宙使用页面 __NEXT_DATA__ 结构化 JSON，修复跨单集正则错配、中文 unicode_escape 乱码；移除失效 /explore 自动发现入口及无验证种子，改为明确节目/单集 ID。仅覆盖公开页面显示的单集，不承诺全历史。
喜马拉雅保留 baseInfo 和音频字段选择顺序，种子必须先真实查询；邻近探测默认关闭、有明确上限，实际专辑 ID 必须匹配。公开 CDN 的 HTTP 地址转换为同资源 HTTPS，保留原 URL；上游声明文件大小单独保留，下载大小以实际传输为准。
公开且非付费音频才进入下载队列；未实现登录、付费内容、全文转写、评论列表、搜索 API 或 HTTP 服务。可选 FFmpeg 转码由部署方配置。
