- 2026-10-05 Management upgrade explicitly authorized by user: human SSO console now manages encrypted channel drafts/publication, app credentials, scoped local RBAC, access invitations and immutable management audit. See docs/management-center.md. This supersedes older read-only-console/file-only-channel limitations below; no human money writes, refunds or automatic-payment confirmation. Bind the initial root administrator to actual issuer/subject/clientId after Launcher account creation; names and generic Auth admin roles are never authorization. Preserve H2I and existing Hub wallet/receipt invariants.
- Payment control data lives in pay_control, encrypted channel payloads use retained control.key (AES-GCM with channel AAD). Draft/file/access/credential seeds are consumed once; redeploy must not overwrite console changes or resurrect revoked grants/credentials. Both API and console receive only their necessary versioned Secret inputs; migration Pods receive neither key nor channels. Auth/session outage must not gate the machine listener. Console writes use shared SSO Origin/CSRF protection, fresh DB grants under mutation lock, revision checks and last-administrator protection.
- Launcher global management is a versioned, authenticated permission catalog + paginated grant projection API, not direct DB access. Current permissions.read cannot write grants or read payment orders. New financial modules and delegation writes require explicit contracts and tests.

Keep two app replicas but do not claim cross-host HA. `MX_PAY_BUILD_PROXY` scopes client/BuildKit/RUN and first single-node PostgreSQL image downloads; preserve parent/runtime environment, existing builder/daemon settings and original database image/identity.
