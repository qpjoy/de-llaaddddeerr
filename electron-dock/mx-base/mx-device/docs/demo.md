# 十分钟内部演示

整个演示先保持右上角「模拟演练」。数据是合成数据，不会连接 18081。不要用模拟成功替代真机验收。

## 1. 单机五任务

点击「五任务演示」：只启用模拟 A，B 暂停。任务为两页搜索、独立详情、依赖搜索的详情、一页搜索、后台一页搜索。观察任务池排队，只有一个执行中；投影逐页更新，事件记录领取与检查点。

通过标准：5 个任务全部完成，均由同一设备执行，相邻 Attempt 时间不重叠；详情依赖先成功的搜索。搜索两页是一个任务中的两个步骤，不是两个可被抢占的任务。

## 2. 中途到来的短任务

等上一个场景完成，点击「优先级演示」。高优先级两页搜索先执行；后台长搜索在 1.5 秒后可领取；高优先级单条详情在 3.5 秒后可领取。

通过标准：当前搜索不被打断，随后详情，再后台搜索。每次领取都说明有效优先级与依赖情况。等待提升每 30 秒一级，此短场景不刻意等待到提升阈值；自动单元测试另行验证防饥饿排序。

## 3. 双模拟设备、一个中断

点击「双机接管演示」，两台模拟设备都接收任务。选中执行中的 A，立即点击右侧「模拟断线」。事件记录旧尝试中断、任务保留；等待 6 秒后，仍在线的 B 能继续领取该任务。旧 A 即使返回迟到结果也不得覆盖 B 的当前尝试。

通过标准：中断任务保持同一个 Job ID，至少两次 Attempt；旧尝试 interrupted、新尝试 succeeded；由 B 完成，且新领取不早于中断后 6 秒。任务名称可打开完整证据。不要点击关机、重启或任何实际手机控制：本页面没有这些动作。

再点击某条检查点事件的「回放此刻」，投影显示带时间标记的历史页面；「返回最新记录」恢复最新证据。投影只依据接口返回，不等于物理屏幕。

## 4. 独立性

打开「连接设置」查看执行器心跳。可在仅模拟且任务完成的环境停止本中心 Worker，观察中心界面和历史仍能读取；恢复 Worker 后再提交模拟任务。此验证只说明本中心运行边界，Hub 是否保持健康还需部署环境提供实际观测，不能仅凭本地模拟宣称线上验证完成。

## 自动验收入口

```bash
node tests/acceptance.mjs .runtime/config.json .runtime/acceptance-report.json
```

会依次运行上面三组场景，约一分钟。要求独立空闲实例，拒绝使用 admin 凭证，HTTP 请求始终携带 `mode=sim`。报告没有管理密码或手机数据，可作为后续 mx-rig 接入的基础证据。

## 真机演示单独过关

按 README 登记原 18081 入口，取得明确空闲并完成独占确认后，仅执行最小任务验证。当前用户提供的 busy 响应不能通过这一关。真机验收前后应记录现有 container ID / imageId 未变、Hub 健康与 MX-H2I 登录/联网指标正常；不得为验收方便重启既有服务。
