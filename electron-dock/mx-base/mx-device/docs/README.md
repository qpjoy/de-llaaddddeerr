## 一分钟结论

- 产品目标是稳定、高可用、高性能的手机机架/集群基础设施，小红书采集是首个参考业务；8787 的设备池等通用产品能力可以统一到 mx-device，但当前实现仍是单机实验版，不是已验收 HA。
- 项目路径：`electron-dock/mx-base/mx-device`，独立 Docker Compose、独立 PostgreSQL、管理端口 18891；不是 Hub 内置模块，也不是 mx-rig 的部署前置依赖。
- 服务器 `mobile-agent` 是一个容器，发布多个端口。8765 是内嵌的侵权处置业务子服务；8787 是设备/业务管理 HTTP 服务；8788 是视频；宿主机 18081 映射容器 18082，接入手机上的旧 PoC，**不是仅凭端口就能认定的另一 mobile-agent 实例**。
- 通用手机观察/控制不以 PoC、VPN 或旧侵权业务为基础依赖。现有 PoC 搜索/详情取数则是另一条可选能力，截图/点击不能自动替代结构化 JSON。
- 当前 mx-device 已有真实截图、过滤后的设备/runner 报告、模拟调度和旧 PoC 兼容；真实点击、全局独占抢占、复位、自动跨机重试尚未开放。
- 本轮新增独立机架总览与任务调度页、持久机架/主机限额和排空、设备归属编辑、模拟任务机架/主机约束。当前分组仍是中心登记信息，不能当作可信硬件拓扑或 HA 证据。
- 手机 PoC 长期 `isBusy:true` 的根因仍未证实。手机曾被确认亮屏、未锁屏且能打开小红书，不得继续把锁屏当成已确认原因，也不得把旧 page=1 当作当前物理屏幕。
- 当前只允许适配原服务。不能为了方便演示重启手机、mobile-agent、ADB 或 VPN；不能影响 Hub、Launcher、MX-H2I 登录/联网。
- `/tmp` 源码是用户从服务器导出的不完整快照，不是已确认的开源 Git 仓库；路径与哈希见源码核实文档。它们可能被系统清理，不能视为永久档案。
