# V2-3：宿主机 Agent 协议、Device Gate 与 SimAgent

日期：2026-10-18。依据 [2.0 方案](device-center-v2-plan-2026-10-15.md) §7、§13 实施，只改 mx-device。**没有部署 18891，没有迁移线上库，没有连接手机、PoC、ADB 或 VPN**，不影响 MX-H2I 登录与联网。前置内容见 [V2-2 节奏账本](v2-2-pacing-ledger-2026-10-15.md)。

## 1. 结论

- **中心与 Agent 的协议 v1 已实现。** Agent 主动连出，宿主机不开入站端口。传输层用 HTTP 长轮询加批量回报，不新增依赖；消息格式与传输无关，以后可以换成 WebSocket。
- **Device Gate 在 Agent 侧强制执行。**
  - 每台设备同时只有一个租约，用单调递增的令牌（token）防护；
  - 指令序号（seq）必须从 1 开始连续；
  - 租约到期后不再开始新指令。
- **派发方式。** 中心签发整段会话的租约，Agent 确认后按"指令"逐条执行：每条指令都写在中心对上一条回执的答复里。因此 Agent 与中心失联时，最多完成手上这一条，然后自然停在安全点。中心任何时候都知道某个租约下是否发出过指令。
- **结算规则。** 租约下没有发出过指令，任务安全回到队列；发出过指令，结果按未知处理并隔离设备，不自动重试。
- **SimAgent。** 模拟驱动（Driver SPI）和 Agent 运行时通过了同一套一致性测试，崩溃、网络分区、调度领导者切换的语义测试也全部通过。`npm run test:pg` 共 **250 项全部通过**（V2-2 后为 234 项）。
- **范围。** 目前只接入模拟设备。真实设备的驱动（PoC、ADB）在 V2-6 接入，会先通过同一套一致性测试。

本轮还按设计稿重做了设备工作台和"场景与策略"页面，见 §7。

## 2. 协议

| 方向 | 接口 / 消息 | 要点 |
| --- | --- | --- |
| Agent → 中心 | `POST /agent/v1/hello` | 实例 ID、版本、驱动、各设备能力，以及**仍持有的租约**。中心对每个未列出的租约立即结算 |
| Agent → 中心 | `POST /agent/v1/heartbeat`（每 5 秒） | 续期租约（20 秒），上报时钟偏差和缓冲条数。中心对每个租约回复 ok / revoked / expired，并告知是否已请求停止 |
| Agent → 中心 | `POST /agent/v1/poll`（长轮询，最长 25 秒） | 取回待确认的租约（`lease.grant`）和停止请求（`attempt.stop`） |
| Agent → 中心 | `POST /agent/v1/report`（每批最多 100 条） | `lease.accept` / `lease.reject` / `command.finished` / `lease.next` / `attempt.stopped` / `signal`。每条消息单独成一个事务，可以重复投递 |
| 中心 → Agent | 回报的答复中的指令 | `run`（一条指令，含 token 和 seq）、`wait`、`yield`（让出给调度器）、`stop`、`done`、`drop` |

- **凭证**：形如 `agentId.secret`，中心只保存 SHA-256 摘要；只在登记或更换时显示一次。停用 Agent 或更换凭证后立即生效，Agent 收到 401/403 后会停止。
- **回执校验**：回执必须回显 commandId、seq、token，并通过原有的身份与输出格式校验，否则按未知处理并隔离设备。
- **答复丢失的修复**：中心已处理、但答复在网络上丢失时，Agent 会重报。中心会把当时发出的那条指令原样再发一次，不会重复执行，也不会误判。

## 3. 故障语义

| 情况 | 行为 | 测试 |
| --- | --- | --- |
| 签发后、确认前 Agent 崩溃 | 重启后的 hello 不再列出该租约。由于没有发出过指令，任务回到队列并重新签发（`attemptCount` 为 2） | 协议测试 |
| 执行中 Agent 崩溃 | hello 不再列出该租约。由于已发出指令，结果按未知处理并隔离设备，不重试 | 协议测试 |
| 短暂网络分区 | Agent 完成手上这一条，把回执留在有界缓冲区，不开始下一条。恢复后补报并继续执行 | 协议测试 |
| 分区超过租约 20 秒加宽限 15 秒 | 中心结算为未知并隔离设备。恢复后补报的回执保存为迟到证据，不会变成成功 | 协议测试（用中心时钟快进） |
| 宽限期内 | 工作台显示"失联待确认"，这期间到达的证据仍然有效 | — |
| 调度领导者切换 | 签发和回报都经过 API 写入数据库，领导者只负责签发。Agent 继续执行，备用领导者接管后继续签发 | PostgreSQL 测试 |
| Agent 拒绝租约（设备忙、能力不符、设备异常） | 没有发出指令：任务回到队列，设备暂停等待核查 | 协议测试 |
| 平台信号 | captcha / rate-limited / logged-out / risk-warning 转给该设备 App 的账号，转入复核并退避（接入 V2-2 账号池）；app-crash 只记录事件 | 协议测试 |
| 管理员停止 | Agent 在下一个安全点停止并复位，任务记为已取消。如果会话停在检查点，中心直接取消 | 协议测试 |
| 伪造或过期的 token、seq 不连续 | 拒绝，或按未知处理并隔离 | 协议测试与一致性测试 |

## 4. 一致性测试套件

`tests/agent-contract.mjs` 可以复用，V2-6 的每个真实驱动上线前都要跑同一套：

- **Device Gate**：比当前小的 token 被拒绝；同一 token 对应不同租约被拒绝；seq 跳号、重复被拒绝；执行中拒绝新租约；到期后拒绝开始新指令；续期与撤销生效。
- **Driver**：如实声明能力（canCancel、canAbort、canFence）；设备忙时拒绝第二条指令；回执回显 commandId、seq、token；超时绝不产生回执；声明支持停止的要给出停止证据；复位要有证据。

SimDriver 全部通过（6 项）。

## 5. 实现

- **中心**：
  - `server/agents.mjs`：登记、hello、心跳、收件箱、回报处理、信号、停止。
  - `server/agent-lease.mjs`：租约常量和签发步骤。
  - 领取与续跑时，Agent 托管的设备得到 `lease.grant`，不在中心进程里执行：
    - 调度器分两轮领取：Agent 设备和本地设备，Agent 设备不占本地执行槽位；
    - 规划器的执行容量上限不再包含 Agent 设备。
- **存储**：
  - 迁移 `013_agents.sql`：新增 `agents` 表，并给设备的 `agentId` 加索引。
  - 新的 `agent` 事务作用域，只锁 Agent 行和它的在途会话；`attempt` 作用域可以附带加载 Agent 行，用于鉴权。
  - 新增字段：
    - 设备：`agentId`、`serial`、`leaseToken`；
    - 会话：`executor`、`agentId`、`token`、`agentState`、`leaseIssued`、`seq`；
    - 指令：`seq`、`token`、`agentId`。
- **Agent**：
  - `server/agent/gate.mjs`：Device Gate。
  - `server/agent/sim-driver.mjs`：SimDriver，含故障注入。
  - `server/agent/host-agent.mjs`：hello、心跳、长轮询，每个租约一个执行循环；回执在内存中有界缓冲（1000 条），随心跳补报。
  - `server/agent/main.mjs`：命令行入口 `npm run agent:sim`。
- **限制**：Agent 托管的设备只运行版本化任务模板（组合任务）。旧的搜索 / 详情任务仍由中心进程执行，不会派给 Agent 设备。

### 使用

1. 在"连接设置 → 宿主机 Agent"中登记 Agent，凭证只显示一次。
2. 把配置写入 `.runtime/agent.json`（不进 git）：

   ```json
   { "center": "http://127.0.0.1:18891", "token": "…", "devices": [{ "serial": "sim-01" }] }
   ```

3. 运行：

   ```bash
   npm run agent:sim
   ```

4. 页面上会出现"N 台待登记"。登记设备时选择机架和模拟 App，之后这台设备的会话就由 Agent 执行。

`npm run dev:sim` 预置一个由模拟 Agent 托管的 6 台"Agent 机架"，并把 `/agent` 代理到预览端口，命令行 Agent 可以直接连 `http://127.0.0.1:5180`。
